## Запуск

```bash
php -S localhost:8000        # з кореня проєкту
```

Сайт віддається з кореня — окремої теки `public/` немає (так задумано). Тому службові
каталоги закриті двома способами: `.htaccess` (для Apache) і перевірка
`defined('KILIMOK') || exit;` на початку кожного PHP-файлу поза `index.php`.

На бойовому сервері `DocumentRoot` має вказувати на корінь проєкту, і `.htaccess` має
бути дозволений (`AllowOverride All`). Якщо використовується nginx — перенесіть правила
з `.htaccess` у конфіг (заборона на `/lib`, `/data`, `/partials`, `/sections`).

## Що де лежить

| Файл | Що редагувати |
|---|---|
| `data/company.php` | адреса, телефони, пошта |
| `data/prices.php` | прайс: розміри, кількість обмінів, ціни |
| `data/gallery.php` | підписи та шляхи до фото галереї |
| `data/clients.php` | логотипи клієнтів |
| `sections/*.php` | текст відповідних розділів |
| `assets/css/style.css` | усі стилі (mobile-first, один файл) |

Розмітка й дані розділені: `data/*.php` повертають масиви об'єктів із `lib/Models.php`,
а `sections/*.php` лише виводять їх.

## Заміна плейсхолдерів

**Фото галереї** — покладіть файли в `assets/img/gallery/` (пропорції 4:3, бажано
1200×900 або більше) і пропишіть шляхи та підписи в `data/gallery.php`. Поточні
`mat-01.svg` … `mat-06.svg` — тимчасові заглушки.

**Логотипи клієнтів** — покладіть у `assets/img/logos/` (пропорції ~3:2, логотип по
центру з полями, прозорий або білий фон) і оновіть `data/clients.php`. Карусель показує
3–6 логотипів у слайді залежно від ширини екрана; кількість логотипів може бути будь-якою.

**Логотип компанії** — `assets/img/logo.svg` (набраний текстом; за потреби замініть на
справжній файл із фірмовим шрифтом).

## Карусель

Розкладку задає CSS-змінна `--per-view` у `assets/css/style.css`:
3 на мобільному → 4 від 640px → 5 від 900px → 6 від 1200px. Щоб змінити — правте
тільки медіа-запити. `assets/js/carousel.js` додає кнопки, крапки й автопрокрутку;
без JavaScript трек залишається прокручуваним списком.

## Прайс

`data/prices.php` містить дані дослівно з листівки. Увага: на першій сторінці листівки
перелічені розміри 60×85, 85×150, 120×180, 115×175, 120×240 і 150×200, а в таблиці цін —
60×85, 150×85, 120×180, 120×240, 150×200 і 150×400. Прайс іде за таблицею; решта розмірів
згадані в розділі «Про килими» як такі, що доступні під замовлення.
