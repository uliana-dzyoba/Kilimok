## Запуск

```bash
php -S localhost:8000        # з кореня проєкту
```

Сайт віддається з кореня — окремої теки `public/` немає (так задумано). Тому службові
каталоги закриті двома способами: `.htaccess` (для Apache) і перевірка
`defined('KILIMOK') || exit;` на початку кожного PHP-файлу поза `index.php`.

На бойовому сервері `DocumentRoot` має вказувати на корінь проєкту, і `.htaccess` має
бути дозволений (`AllowOverride All`). Якщо використовується nginx — перенесіть правила
з `.htaccess` у конфіг (заборона на `/lib`, `/data`, `/partials`, `/sections`).

## Що де лежить


| Файл                   | Що редагувати                           |
| ---------------------- | --------------------------------------- |
| `data/company.php`     | адреса, телефони, пошта                 |
| `data/prices.php`      | прайс: розміри, кількість обмінів, ціни |
| `data/gallery.php`     | підписи та шляхи до фото галереї        |
| `data/clients.php`     | логотипи клієнтів                       |
| `sections/*.php`       | текст відповідних розділів              |
| `assets/css/style.css` | усі стилі (mobile-first, один файл)     |


## Мовні версії

Українська — `/`, англійська — `/en/` (`en/index.php` лише задає `SITE_LANG = 'en'` і
підключає кореневий `index.php`). Усі тексти записані парами прямо на місці:
`t('Ціни', 'Prices')` — тож, змінюючи український текст, оновіть і англійський поруч.
Перемикач мови — у шапці, `hreflang`/`canonical` — у `partials/head.php`.

Розмітка й дані розділені: `data/*.php` повертають масиви об'єктів із `lib/Models.php`,
а `sections/*.php` лише виводять їх.

## Заміна плейсхолдерів

**Фото галереї** — файли в `assets/img/gallery/` (JPEG, довша сторона до 1600 px),
шляхи та alt-тексти — у `data/gallery.php`. Галерея — слайдер по 6 фото: у кожному
слайді 1-ше та 4-те фото стоять у широких клітинках, тож туди краще ставити горизонтальні
знімки. Фото обрізаються під клітинку (`object-fit: cover`) по центру.

**Логотипи клієнтів** — PNG 480×320 у `assets/img/logos/` (прозорий фон, логотип по
центру з полями); назва клієнта й ім'я файлу — у `data/clients.php` (`null` замість імені
файлу — плейсхолдер з назвою). Карусель показує
2–5 логотипів у слайді залежно від ширини екрана; кількість логотипів може бути будь-якою.

**Логотип компанії** — `assets/img/logo.svg`.

## Карусель

Той самий `assets/js/carousel.js` працює і для галереї (`--per-view: 1`, лише крапки,
інтервал задано атрибутом `data-carousel-interval`). Для логотипів розкладку задає CSS-змінна `--per-view` у `assets/css/style.css`:
2 на мобільному → 3 від 640px → 4 від 900px → 5 від 1200px. Щоб змінити — правте
тільки медіа-запити. `assets/js/carousel.js` додає кнопки, крапки й автопрокрутку;
без JavaScript трек залишається прокручуваним списком.

## Прайс

`data/prices.php` містить ціни дослівно з прайсу від 01.10.2026 (аркуш «Лист2» у
`tmp/prices.xls`). Кольори клітинок в аркуші позначають кількість обмінів на місяць:
без заливки — 1, фіолетовий — 2, блакитний — 4, зелений — 8, жовтий — 12.

Розміри в прайсі: 60×85, 150×85 (120×85), 115×175 (100×170), 150×200, 150×240 і
150×400 (115×400). На першій сторінці листівки перелічені також 85×150 і 120×240 —
вони згадані в розділі «Про килими» (`sections/features.php`) як такі, що
доступні під замовлення.
